## Part 00. 먼저 알아두기

이 가이드는 클로드로 PPT를 **한 장 예쁘게** 뽑는 법이 아닙니다. 레퍼런스를 고르고, 기준을 저장한 뒤, 같은 기준으로 여러 장을 반복해서 만드는 흐름을 정리합니다.

코딩·디자인을 몰라도 따라갈 수 있게 썼습니다. 도구는 클로드(Claude)와 클로드 디자인(또는 동등한 디자인 캔버스)을 기준으로 합니다.

**한 줄로 요약하면:** 레퍼런스 → 디자인 시스템 → 슬라이드 순서로 갑니다. 슬라이드부터 시작하면 AI 티가 납니다.

### 이 가이드에서 쓰는 말

- **레퍼런스**: 내가 만들고 싶은 분위기·구조를 보여주는 기존 슬라이드·랜딩·브랜드 자료
- **디자인 시스템**: 색·폰트·간격·컴포넌트 규칙을 한곳에 모아 둔 기준
- **슬라이드**: 그 기준 위에서 실제로 뽑는 장표

### 준비물

- 만들고 싶은 PPT의 목적 한 줄 (예: 투자 피치, 세일즈 제안, 강의 자료)
- 레퍼런스 후보 5~10개 (이미지·링크·PDF 캡처)
- 브랜드가 있으면 로고·메인 컬러·쓰는 폰트 이름

## Part 01. 레퍼런스를 고르는 기준

좋은 레퍼런스는 “예쁘다”가 아니라 **구조가 분명한가**입니다.

### 고를 때 보는 네 가지

1. **정보 밀도** — 한 장에 문장이 너무 많으면 제외
2. **시선 흐름** — 제목 → 핵심 숫자/문장 → 보조 설명이 위에서 아래로 읽히는가
3. **여백** — 요소끼리 붙지 않고, 그룹이 나뉘어 보이는가
4. **반복 가능성** — 같은 레이아웃으로 10장을 더 뽑을 수 있을 것 같은가

### 피해야 할 레퍼런스

- 그라데이션·글로우·장식이 주제인 장표
- 사진이 대부분이고 텍스트 구조가 없는 장표
- “AI가 만든 티”가 나는 균일 카드 나열만 있는 장표

### 실습

레퍼런스 이미지를 클로드에 넣고 아래를 요청합니다.

```text
이 슬라이드 레퍼런스를 보고, 레이아웃 구조만 설명해 주세요.
- 그리드(열/행)
- 제목·본문·강조 요소의 위치
- 여백과 정렬 규칙
색과 장식은 무시하고, 구조만 3~5문장으로 적어 주세요.
```

답이 모호하면 레퍼런스를 바꿉니다. 구조가 말로 설명되지 않으면 기준으로 쓰기 어렵습니다.

## Part 02. 디자인 시스템으로 저장하기

레퍼런스에서 뽑은 규칙을 **한 번만** 문서로 고정합니다. 이후 슬라이드는 이 문서에 묶습니다.

### 시스템에 넣을 항목

- 배경 / 카드 / 강조 색 (가능하면 3색 이하)
- 제목·본문·캡션 폰트와 크기 단계 (2~3단계면 충분)
- 기본 간격 (예: 8의 배수)
- 버튼·배지·카드 모서리 규칙
- 금지 사항 (그림자 과다, 이모지, 그라데이션 남발 등)

### 프롬프트 예시

```text
나는 PPT용 디자인 시스템을 만듭니다. 아래 레퍼런스 분석과 내 브랜드 정보를 합쳐,
재사용 가능한 디자인 시스템 문서를 작성해 주세요.

[브랜드]
- 이름:
- 톤: 담백한 존댓말, 과장 없음
- 메인 컬러:
- 폰트:

[레퍼런스에서 가져온 구조]
(여기에 Part 01 결과 붙여넣기)

출력 형식:
1) 색 토큰 표
2) 타이포 스케일
3) 간격·레이아웃 규칙
4) 슬라이드 템플릿 3종(표지/본문/비교)의 와이어 설명
5) 하지 말 것 목록
```

클로드 디자인(또는 동등 도구)에 이 문서를 프로젝트 지침·캔버스 기준으로 저장해 둡니다. **매 장마다 새로 설명하지 않는 것**이 핵심입니다.

## Part 03. 슬라이드를 뽑는 순서

시스템이 준비되면 슬라이드는 “생성”보다 **채우기**에 가깝습니다.

### 추천 순서

1. 목차(스토리 아크)를 먼저 확정 — 장 수만 적어도 됩니다
2. 표지 → 문제 → 해결 → 증거 → 다음 행동 순으로 뼈대 작성
3. 장마다 **한 메시지**만 넣기
4. 디자인 시스템을 붙인 채 레이아웃 생성
5. 사람이 고치고, 다시 생성하지 말고 **첨삭** 요청

### 장표 생성 프롬프트

```text
아래 디자인 시스템을 守り, [장 제목] 슬라이드 1장을 만들어 주세요.
메시지 한 줄: ...
포함할 정보: ...
금지: 시스템 밖 색, 새 폰트, 장식용 아이콘 남발
출력: 레이아웃 설명 + 실제 들어갈 문장(한국어)
```

### 고칠 때 쓰는 말

- “더 예쁘게” 대신 **“여백을 한 단계 늘려 주세요”**, **“제목 계층만 남겨 주세요”**
- 후보가 여러 개면 **“1안과 3안 중 정보 밀도가 낮은 쪽을 기준으로 합쳐 주세요”**

## Part 04. AI 티를 줄이는 체크리스트

내보내기 전에 아래만 확인해도 완성도가 올라갑니다.

- [ ] 한 장에 메시지가 두 개 이상인가
- [ ] 같은 역할의 텍스트 크기가 장마다 제각각인가
- [ ] 카드·버튼 스타일이 장마다 다른가
- [ ] 장식(글로우, 그라데이션, 입체 그림자)이 본문보다 눈에 띄는가
- [ ] 숫자·고유명사에 오타가 있는가

통과하지 못하면 디자인 시스템으로 돌아가 규칙을 보강하고, 슬라이드만 다시 뽑습니다.

## Part 05. 반복 제작으로 확장하기

한 번 만든 시스템은 PPT 밖에서도 씁니다.

- 같은 토큰으로 랜딩 히어로 카피 톤 맞추기
- 같은 레이아웃 규칙으로 SNS 카드 뽑기
- 같은 “하지 말 것”으로 팀원·외주 없이 혼자 검수하기
