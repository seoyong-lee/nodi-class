<h2 id="part-00">Part 00. 먼저 알아두기</h2>

### 제미나이를 질문 창으로만 쓰고 있다면

물어보고, 답을 복사해서 문서에 붙이고, 모양을 다시 다듬는 데서 끝났다면 제미나이의 절반도 못 쓰고 계신 거예요. 지금의 제미나이는 엑셀과 PDF 파일을 직접 만들어 주고, 발표 자료와 간단한 계산기, 소개 웹페이지까지 만들어 줍니다.

이 가이드북은 혼자 사업하는 분이 외주를 맡기거나 사람을 뽑아서 해결하던 일을 제미나이에게 넘길 수 있도록, 영상에서 보여 드린 기능 7가지와 보너스 기능 하나를 순서대로 정리한 자료입니다.

이런 분을 기준으로 썼어요.

- 혼자 창업을 준비하거나 운영 중인 대표
- 매장을 운영하는 자영업자
- 온라인 쇼핑몰·스마트스토어 운영자
- 직접 만든 서비스를 혼자 운영하는 대표

### 무료로 되는 것, 유료가 필요한 것

| 기능 | 무료 계정 | 알아둘 점 |
|---|---|---|
| 파일 생성 (엑셀·PDF·워드 등) | 가능 | 2026년 4월 말부터 전체 사용자에게 제공 |
| 이미지 생성 | 가능 (나노 바나나 2) | 나노 바나나 프로로 다시 만들기는 유료 요금제 전용 |
| 캔버스 (슬라이드·앱·만들기 버튼) | 가능 | 만 18세 미만은 일부 기능 제한 |
| 젬 | 가능 | 새 젬은 웹(gemini.google.com)에서 만듭니다 |
| 지메일·드라이브 연결 | 순차 제공 | 개인 인텔리전스 기능, 만 18세 이상 |
| 동영상 만들기 | 불가 | 개인 계정은 구글 AI 요금제 필요 |

<Callout tone="warn">
2026년 9월 기준 구글 공식 도움말로 확인한 내용입니다. 제미나이는 메뉴 이름과 제공 범위가 자주 바뀌고 계정·지역별로 순서대로 열리는 기능이 많아서, 내 화면과 조금 다를 수 있어요. 이 가이드북은 컴퓨터 웹(gemini.google.com)을 기준으로 설명합니다.
</Callout>

### 좋은 요청에는 네 가지가 들어 있습니다

"견적서 만들어 줘"라고만 하면 제미나이는 빈칸을 전부 짐작으로 채웁니다. 이 책의 프롬프트는 모두 아래 네 가지를 채우는 방식으로 썼어요.

1. 무엇을 — 만들 결과물과 거기 들어갈 항목
2. 누구에게 — 결과물을 보는 사람과 쓰는 상황
3. 어떤 형식으로 — 파일 종류, 장 수, 분량
4. 어떤 조건으로 — 꼭 지킬 것과 하지 말아야 할 것

<Callout tone="tip">
모든 프롬프트는 대괄호 [ ] 부분만 내 상황으로 바꾸면 그대로 쓸 수 있습니다. 예시가 적힌 대괄호는 지우고 내 내용으로 채워 주세요.
</Callout>

### 이 책에서 사용하는 프롬프트

기능마다 핵심 프롬프트를 하나씩, 모두 9개를 씁니다. 처음 나오는 Part에서 바로 사용하고, 마지막 부록에 다시 모아 두었어요. 작업 중에 짧게 던지는 한 줄 요청은 Quick Command로 따로 표시합니다.

<h2 id="part-01">Part 01. 시작 전 필수 세팅</h2>

### 세 가지를 먼저 켜 두세요

이 세팅을 건너뛰면 뒤에 나오는 지메일 연결이나 드라이브 내보내기가 안 되는 경우가 많습니다. 설정 및 도움말에서 개인 인텔리전스(Personal Intelligence)로 들어가 아래 순서대로 진행하세요.

1. 연결된 앱에서 **Google Workspace**를 켭니다. 지메일, 캘린더, 드라이브 내용을 제미나이가 찾아볼 수 있게 됩니다.
2. **메모리**를 켭니다. 지난 대화에서 나온 우리 회사·서비스 이야기를 기억해서 답에 반영합니다.
3. **제미나이 요청 사항**에 내가 누구인지, 어떻게 답해 주면 좋은지를 한 번만 적어 둡니다.

<Callout tone="warn">
개인 인텔리전스는 만 18세 이상 계정에 순차적으로 열리고 있어서, 메뉴가 아직 안 보일 수 있어요. 앱을 연결하면 제미나이가 메일과 문서 내용을 참고해 답하게 되니, 어떤 앱을 연결할지는 직접 판단해서 고르세요. 연결은 언제든 끌 수 있습니다.
</Callout>

### 요청 사항은 이렇게 적습니다

요청 사항에는 두 가지만 적으면 됩니다. 나와 내 사업에 대한 정보, 그리고 답을 받고 싶은 방식입니다.

<Prompt id="instructions" index="01" name="요청 사항" when="설정 → 개인 인텔리전스 → 제미나이 요청 사항에 붙여 넣습니다. 한 번에 안 들어가면 항목별로 나눠서 추가하세요.">

```text
## 나와 내 사업
- 나는 [업종: 예) 수제 반려동물 간식 온라인 쇼핑몰]을 혼자 운영하는 대표야.
- 주요 고객은 [고객: 예) 30~40대 반려인]이고, 주로 [판매 채널: 예) 스마트스토어와 인스타그램]에서 판매해.
- 제미나이는 주로 [용도: 예) 정산, 견적서, 고객 응대, 상세페이지 문구]에 쓸 거야.

## 답변 방식
- 핵심부터 먼저 말하고, 이유는 그다음에 짧게 설명해 줘.
- 바로 실행할 수 있는 순서대로 정리해 줘.
- 전문 용어는 쓰지 말고, 꼭 필요하면 쉬운 말로 풀어 줘.
- 존댓말로 답해 줘.

## 꼭 지켜 줄 것
- 내가 알려 주지 않은 숫자·가격·정책은 지어내지 말고 [확인 필요]로 표시해 줘.
- 요청이 애매하면 만들기 전에 먼저 물어봐 줘.
- 파일을 요청하면 화면에 표로만 보여 주지 말고 실제로 열 수 있는 파일로 만들어 줘.
```

</Prompt>

### 작성 예시 (혼자 서비스를 운영하는 대표 기준)

<Prompt id="instructions-example" name="요청 사항 예시" when="위 템플릿의 첫 부분을 채운 예시입니다. 나머지는 그대로 두셔도 됩니다.">

```text
## 나와 내 사업
- 나는 동네 필라테스 강사들이 쓰는 수업 예약 앱을 혼자 운영하는 대표야.
- 주요 고객은 1인 필라테스 스튜디오 원장님들이고, 월 구독료를 받고 있어.
- 제미나이는 주로 입점 제안 자료, 고객 문의 답장, 월별 정산에 쓸 거야.
```

</Prompt>

### 뭘 적을지 막막하다면

요청 사항에 뭘 적어야 할지 모르겠다면 이것도 제미나이에게 맡기세요. 질문에 편하게 답한 뒤, 정리된 내용을 복사해서 붙여 넣으면 됩니다.

<Prompt id="q-instructions-interview" kind="quick" name="요청 사항 인터뷰">

```text
제미나이 요청 사항에 내 사업에 대해 적어 두고 싶은데, 뭘 적어야 할지 모르겠어.
나한테 질문을 한 번에 하나씩 해 주고, 내 답을 바탕으로 요청 사항에 붙여 넣을 수 있게 정리해 줘.
```

</Prompt>

<h2 id="part-02">Part 02. 말 한마디로 엑셀·PDF 파일 만들기</h2>

### 복사하고 붙여 넣는 단계가 사라졌습니다

2026년 4월 말부터 제미나이는 대화창에서 바로 파일을 만들어 줍니다. 구글 문서·시트·슬라이드, PDF, 워드(.docx), 엑셀(.xlsx), CSV 같은 형식을 지원하고, 만든 파일은 내 컴퓨터로 내려받거나 구글 드라이브로 보낼 수 있어요. AI 답변을 복사해서 엑셀에 붙이고, 다시 PDF로 저장하던 과정을 건너뛸 수 있게 된 겁니다.

### 월별 정산표 만들기

<Prompt id="settlement" index="02" name="정산표" when="매달 매출과 지출을 한곳에 모으고, 순이익을 자동으로 계산하고 싶을 때 씁니다.">

```text
올해 매출·지출을 정리하는 정산용 엑셀 파일을 만들어 줘.

[시트 구성]
- 첫 번째 시트 '대시보드': 1월~12월의 매출, 비용, 순이익을 월별로 자동 집계
- 나머지 12개 시트: '1월'부터 '12월'까지 하나씩

[월별 시트]
- 열: 날짜 / 구분(매출·고정비·변동비) / 항목 / 금액 / 메모
- 맨 아래에 매출 합계, 고정비 합계, 변동비 합계, 순이익(매출 − 고정비 − 변동비)을 수식으로 계산
- 내가 숫자를 넣는 칸과 수식이 들어간 칸을 색으로 구분

[대시보드]
- 각 월 시트의 합계를 수식으로 불러오기 (숫자를 직접 적지 말 것)
- 월별 매출·순이익 막대그래프 1개, 순이익 추이 꺾은선그래프 1개
- 연간 합계와 월평균 순이익

[조건]
- 고정비 항목 예시: [임대료, 통신비, 프로그램 구독료]
- 변동비 항목 예시: [재료비, 포장비, 배송비, 광고비]
- 1월 시트에만 예시 숫자를 몇 줄 넣어서 대시보드가 제대로 계산되는지 보이게 해 줘.
- 실제로 열 수 있는 엑셀(.xlsx) 파일로 만들어 줘.
```

</Prompt>

파일을 받으면 1월 시트의 숫자를 하나 바꿔 보세요. 대시보드 숫자와 그래프가 같이 바뀌면 제대로 만들어진 파일입니다. 확인이 끝나면 예시 숫자는 지우고 쓰면 됩니다.

<Prompt id="q-formula-fix" kind="quick" name="수식으로 바꾸기">

```text
대시보드의 월별 합계가 숫자로 적혀 있어. 각 월 시트의 합계 칸을 참조하는 수식으로 바꿔서 파일을 다시 만들어 줘.
```

</Prompt>

### 상담 메모로 견적서 만들기

통화나 카톡으로 받은 상담 내용은 길고 정리가 안 돼 있기 마련이에요. 메모를 그대로 붙여 넣고, 견적서에 들어갈 항목을 정해서 요청합니다.

<Prompt id="quote" index="03" name="견적서" when="고객·거래처와 상담한 뒤, 상담 내용을 한 장짜리 견적서로 정리해 보낼 때 씁니다.">

```text
아래 상담 메모를 바탕으로 한 장짜리 견적서를 만들어 줘.

[상담 메모]
(여기에 통화·카톡 상담 내용을 그대로 붙여 넣기)

[견적서에 넣을 항목]
- 상단: 견적서 제목, 견적 번호, 작성일, 유효기간([예: 작성일로부터 14일])
- 공급자: [상호 / 대표자 / 사업자등록번호 / 연락처]
- 받는 곳: 메모에 나온 고객명 또는 회사명
- 품목표: 품목 / 내용 / 수량 / 단가 / 금액
- 합계: 공급가액, 부가세, 총액 (부가세는 [별도 표기 / 포함가] 방식으로)
- 요청 사항 요약, 예산, 납기일, 결제 조건
- 비고: 견적에 포함되지 않는 작업

[조건]
- 메모에 없는 금액·수량·날짜는 지어내지 말고 [확인 필요]로 표시해 줘.
- 예산과 견적 총액이 맞지 않으면 비고에 한 줄로 알려 줘.
- 흑백 위주의 깔끔한 문서 스타일로, 실제로 열 수 있는 PDF 파일로 만들어 줘.
```

</Prompt>

<Callout tone="warn">
견적서는 금액이 걸린 문서입니다. 보내기 전에 품목, 수량, 단가, 합계를 반드시 직접 확인하세요. 고칠 일이 많다면 PDF 대신 워드(.docx)나 구글 문서로 먼저 받아서 수정한 뒤 PDF로 저장하는 편이 편합니다.
</Callout>

### 파일 형식은 이렇게 고르세요

| 이런 결과물이 필요하면 | 이 형식으로 요청 |
|---|---|
| 숫자를 계속 넣고 계산할 표 | 엑셀(.xlsx) 또는 구글 시트 |
| 그대로 보낼 확정 문서 | PDF |
| 받는 쪽에서 고칠 수도 있는 문서 | 워드(.docx) 또는 구글 문서 |
| 다른 프로그램에 옮길 목록 | CSV |

<Callout tone="tip">
프롬프트 마지막에 "실제로 열 수 있는 [형식] 파일로 만들어 줘"를 꼭 붙이세요. 이 한 줄이 없으면 화면에 표 모양의 글자만 나오는 경우가 많습니다.
</Callout>

<h2 id="part-03">Part 03. 이미지 생성으로 사용법 카드 만들기</h2>

### 글자가 들어간 이미지도 만들 수 있어요

제미나이의 기본 이미지 모델은 나노 바나나 2입니다. 예전보다 글자 철자를 정확하게 넣고, 인포그래픽처럼 정보가 들어간 이미지도 잘 만듭니다. 유료 요금제를 쓰고 있다면 만든 이미지의 더보기 메뉴에서 **Pro로 다시 만들기**를 눌러 나노 바나나 프로로 더 정교하게 다시 뽑을 수 있어요.

제품이나 서비스 사용법을 단계별 카드로 정리할 때 특히 쓸모가 있습니다.

<Prompt id="usage-card" index="04" name="사용법 카드" when="상품·서비스 사용법을 상세페이지나 SNS에 올릴 한 장짜리 이미지로 만들 때 씁니다.">

```text
우리 [제품/서비스: 예) 반려동물 영양 파우더]의 사용법을 한 장짜리 인포그래픽 이미지로 만들어 줘.

[문구] 아래 문구를 글자 그대로 넣어 줘.
- 제목: "[예: 하루 한 번, 3단계면 끝나요]"
- 1단계: "[예: 스푼으로 1회분 덜기]"
- 2단계: "[예: 사료 위에 골고루 뿌리기]"
- 3단계: "[예: 개봉 후에는 냉장 보관]"

[디자인]
- 단계마다 카드로 나누고, 카드마다 번호와 간단한 그림을 넣어 줘.
- 세로형 [4:5] 비율, 흰 배경에 [브랜드 색: 예) 짙은 초록]을 포인트로
- 글자는 크고 굵게, 카드 하나에 문장은 한 줄만
- 모든 글자는 한글로 쓰고, 위에 적은 문구 말고는 글자를 넣지 마.
```

</Prompt>

<Callout tone="tip">
넣을 문구를 따옴표 안에 정확히 적어 주면 엉뚱한 글자가 섞일 가능성이 줄어요. 한 부분만 틀렸다면 처음부터 다시 만들지 말고, 그 부분만 고쳐 달라고 요청하세요.
</Callout>

<Prompt id="q-image-text-fix" kind="quick" name="글자만 수정">

```text
다른 부분은 그대로 두고, 2단계 문구만 "[바꿀 문구]"로 고쳐 줘.
```

</Prompt>

### 메인 배너는 배경만 맡기세요

상세페이지 메인 배너나 로고처럼 브랜드의 얼굴이 되는 이미지는 통째로 AI에게 맡기지 않는 편이 좋습니다. 이미지 안에 박힌 글자는 나중에 고치기 어렵고, 실제 상품과 다르게 그려지면 오해를 부를 수 있어요. 배경만 AI로 만들고, 문구와 상품 사진은 미리캔버스나 캔바 같은 편집 도구에서 직접 올리세요.

<Prompt id="q-banner-background" kind="quick" name="배너 배경만 만들기">

```text
상세페이지 메인 배너에 쓸 배경 이미지만 만들어 줘.
- 가로형 [16:9] 비율
- 왼쪽 절반은 문구를 올릴 수 있게 단색에 가까운 빈 공간으로 둬.
- 오른쪽에는 [분위기: 예) 햇살이 드는 원목 테이블 위의 작은 화분과 리넨 천]을 배치해 줘.
- 글자, 로고, 상품은 넣지 마.
```

</Prompt>

### 쓰기 전에 이것만 확인하세요

- 글자에 오타나 깨진 글자가 없는가
- 실제 상품과 다른 모양이나 구성으로 보이지 않는가
- 다른 브랜드의 로고나 캐릭터가 섞여 들어가지 않았는가
- 내려받은 해상도가 쓰려는 곳에 충분한가 (무료 계정은 1K, 구글 AI 요금제는 2K로 내려받습니다)

<h2 id="part-04">Part 04. 캔버스로 거래처 제안 자료 만들기</h2>

### 캔버스는 결과물을 옆에 펼쳐 두고 작업하는 공간이에요

다음 주에 거래처 미팅이나 입점 제안이 잡혔는데 발표 자료가 하나도 없다면 캔버스를 여세요. 대화창 아래의 **+(파일 추가)** 버튼을 누르고 **캔버스**를 고른 뒤 요청하면, 오른쪽에 슬라이드가 펼쳐집니다.

이때 두 가지를 꼭 적으세요. "구글 슬라이드"라는 형식, 그리고 몇 장인지 숫자입니다. 이 두 가지가 빠지면 슬라이드 대신 긴 글이 나오기 쉽습니다.

<Prompt id="proposal" index="05" name="제안 자료" when="거래처 미팅, 입점 제안, 협업 제안에 쓸 발표 자료가 급하게 필요할 때 씁니다.">

```text
우리 [서비스/상품] 소개 및 제안용 구글 슬라이드를 7장으로 만들어 줘.

[받는 사람과 목적]
- 받는 사람: [예) 입점을 제안할 편집숍 바이어]
- 목적: [예) 다음 달 입점 조건 협의]

[장별 구성]
1장. 표지 — 회사명과 한 줄 소개
2장. 우리가 해결하는 문제 — 고객이 겪는 불편 한 가지
3장. 상품·서비스 구성 — 대표 [3]가지
4장. 강점 — 다른 곳과 다른 점 [2~3]가지
5장. 성과와 근거 — [예) 재구매율, 후기 수] (내가 준 숫자만 사용)
6장. 제안 조건 — [예) 공급가, 최소 주문 수량, 정산 주기]
7장. 다음 단계 — 연락처와 일정 제안

[조건]
- 한 장에는 메시지 하나만 담고, 제목은 결론을 담은 한 문장으로 써 줘.
- 장마다 발표자 메모를 3줄 이내로 넣어 줘.
- 내가 알려 주지 않은 숫자는 지어내지 말고 [확인 필요]로 표시해 줘.
- [흰 배경에 브랜드 색 한 가지] 톤으로 통일해 줘.

[우리 정보]
(회사 소개, 상품 목록, 가격, 성과 숫자를 여기에 붙여 넣거나 파일로 첨부)
```

</Prompt>

### 고칠 게 있으면 한 번에 몰아서 요청하세요

마음에 안 드는 부분은 말로 고치면 됩니다. 다만 수정 요청을 보내면 슬라이드를 처음부터 다시 만드는 경우가 많아서 매번 시간이 걸려요. 고칠 내용을 모아서 한 번에 보내는 게 시간을 아끼는 방법입니다.

<Prompt id="q-proposal-batch-fix" kind="quick" name="한 번에 수정">

```text
아래 수정 사항을 한 번에 반영해 줘.
- 배경은 흰색으로 바꿔 줘.
- 중요한 숫자만 [브랜드 색]으로 강조해 줘.
- 모든 장의 글자 수를 지금의 절반으로 줄여 줘.
- 5장의 숫자는 [확인한 값]으로 바꿔 줘.
```

</Prompt>

### 파일로 내보내기

캔버스 오른쪽 위의 **공유 및 내보내기**를 누르면 구글 슬라이드나 PDF로 내보낼 수 있습니다.

1. 함께 고치거나 계속 쓸 자료라면 구글 슬라이드로 내보냅니다.
2. 그대로 보낼 자료라면 PDF로 내보냅니다.
3. 파워포인트 파일이 필요한데 메뉴에 PPTX가 없다면, 구글 슬라이드로 내보낸 뒤 **파일 → 다운로드 → Microsoft PowerPoint(.pptx)** 를 고르세요.

<Callout tone="warn">
파워포인트로 옮기면 글꼴이나 줄바꿈이 조금 달라질 수 있어요. 거래처에 보내기 전에 파일을 직접 한 번 열어서 확인하세요.
</Callout>

<h2 id="part-05">Part 05. 코딩 몰라도 만드는 원가 계산기</h2>

### 말로 설명하면 앱이 됩니다

캔버스는 문서와 슬라이드뿐 아니라 입력창과 버튼이 있는 작은 프로그램도 만들어 줍니다. 코드는 제미나이가 알아서 쓰고, 우리는 평소 말하듯이 어떤 칸이 필요하고 어떻게 계산하는지만 설명하면 돼요.

### 먼저 '마진율'부터 정확히 정하세요

"마진율 30%를 붙여 줘"라는 말은 두 가지로 해석됩니다. 어느 쪽으로 계산하느냐에 따라 판매가가 꽤 달라져요.

| 계산 방식 | 식 | 원가가 10,000원일 때 판매가 |
|---|---|---|
| 원가에 30%를 더하기 | 원가 × 1.3 | 13,000원 (판매가 기준으로는 약 23%가 남음) |
| 판매가의 30%를 남기기 | 원가 ÷ 0.7 | 약 14,286원 (판매가 기준으로 30%가 남음) |

아래 프롬프트는 판매가 기준으로 계산하도록 적었습니다. 판매 채널 수수료까지 빼고 목표 마진이 남도록 설계했어요.

<Prompt id="cost-calculator" index="06" name="원가 계산기" when="상품 가격을 정하거나 견적을 낼 때마다 같은 계산을 반복하고 있다면 씁니다.">

```text
캔버스에서 우리 상품의 판매가를 계산하는 원가 계산기 앱을 만들어 줘.

[입력 칸]
- 재료비 (원)
- 포장비 (원)
- 작업 시간 (분)과 시급 (원) → 인건비는 자동 계산
- 배송비 (원)
- 판매 채널 수수료율 (%)
- 목표 마진율 (%) — 기본값 30

[계산 방식]
- 원가 합계 = 재료비 + 포장비 + 인건비 + 배송비
- 마진율은 판매가 기준으로 계산해 줘.
- 권장 판매가 = 원가 합계 ÷ (1 − 수수료율 − 목표 마진율)
- 수수료율과 목표 마진율의 합이 100% 이상이면 계산하지 말고 안내 문구를 보여 줘.
- 부가세 10%를 더한 가격도 함께 보여 줘.
- 100원 단위로 올림한 가격을 따로 보여 줘.

[화면]
- 숫자를 입력하면 바로 계산되게 해 줘.
- 결과에는 원가 합계, 수수료, 남는 금액, 권장 판매가를 크게 보여 줘.
- 휴대폰에서도 보기 편하게 세로 한 줄로 배치해 줘.
- 입력값은 저장하지 말고, 새로고침하면 비워지게 해 줘.
```

</Prompt>

서비스를 판매한다면 재료비 대신 작업 시간과 시급을 중심으로 바꾸면 됩니다.

<Prompt id="q-service-calculator" kind="quick" name="서비스용으로 바꾸기">

```text
재료비·포장비·배송비 칸은 빼고, 작업 시간(시간)과 시급, 외주비, 도구 구독료를 입력하는 서비스 견적 계산기로 바꿔 줘.
계산 방식과 화면 조건은 그대로 유지해 줘.
```

</Prompt>

### 만든 계산기는 꼭 한 번 검산하세요

재료비에 10,000원을 넣고 나머지 비용과 수수료율은 0, 목표 마진율은 30%로 두세요. 권장 판매가가 약 14,286원으로 나오면 식이 제대로 들어간 겁니다. 다른 숫자가 나오면 "권장 판매가 계산식을 다시 확인해 줘"라고 요청하세요.

### 링크로 공유하기

캔버스 오른쪽 위의 **공유 및 내보내기 → 공유**를 누르면 링크가 만들어집니다. 이 링크를 직원이나 파트너에게 카톡으로 보내면 각자 열어서 바로 쓸 수 있어요. 공유 링크는 제미나이 모바일 앱이 아니라 gemini.google.com에서 열리니, 휴대폰에서는 브라우저로 열린다고 함께 안내해 주세요.

<Callout tone="warn">
구글 도움말에 따르면 공유 링크를 가진 사람은 누구나 그 앱에 저장된 데이터를 보고 수정할 수 있습니다. 링크로 나눌 계산기에는 저장 기능을 넣지 말고, 우리 회사의 실제 원가를 기본값으로 넣어 두지 마세요.
</Callout>

<Callout tone="tip">
부가세나 수수료를 어떻게 반영할지는 과세 유형과 판매 채널에 따라 달라집니다. 계산기는 가격을 정할 때 참고하는 도구로 쓰고, 세금 문제는 세무 전문가에게 확인하세요.
</Callout>

<h2 id="part-06">Part 06. 젬으로 나만의 담당 직원 만들기</h2>

### 매번 하던 설명을 한 번만 저장합니다

AI를 쓸 때 시간이 가장 많이 새는 곳은 "우리 브랜드는 이런 말투고, 이런 문의가 자주 와"를 매번 다시 설명하는 순간입니다. 젬은 이 설명을 저장해 둔 나만의 제미나이예요. 무료 계정에서도 만들 수 있습니다.

1. gemini.google.com 왼쪽에서 **젬 둘러보기**를 누르고 **새 젬**을 누릅니다.
2. 이름을 정합니다. 예를 들어 "고객 응대 담당"이라고 적습니다.
3. 요청 사항(지침) 칸에 아래 프롬프트를 채워서 붙여 넣습니다.
4. 오른쪽 미리보기 창에서 실제 문의를 하나 넣어 시험해 봅니다.
5. 결과가 괜찮으면 **저장**을 누릅니다. 미리보기만 해서는 저장되지 않아요.

### 지침에는 네 가지를 적습니다

구글 공식 도움말도 젬 지침에 아래 네 가지를 채우라고 안내합니다. 전부 쓰지 않아도 되지만, 많이 채울수록 결과가 안정적입니다.

| 항목 | 적을 내용 |
|---|---|
| 역할 | 어떤 담당자로 일할지 |
| 할 일 | 무엇을 받아서 무엇을 만들어 줄지 |
| 배경 | 브랜드 말투, 자주 오는 문의, 정책 |
| 형식 | 답의 구성과 길이 |

<Prompt id="cs-gem" index="07" name="고객 응대 젬" when="젬의 요청 사항(지침) 칸에 붙여 넣습니다. 대괄호를 우리 정책으로 채운 뒤 저장하세요.">

```text
## 역할
- 너는 [브랜드명]의 고객 응대 담당자야.
- 고객이 보낸 문의를 읽고, 우리 브랜드 말투로 바로 보낼 수 있는 답장을 써.

## 할 일
- 내가 문의 내용을 붙여 넣으면 답장 초안을 써 줘.
- 답장 위에 문의 유형(배송 / 교환·환불 / 상품 문의 / 불만 / 기타)을 한 줄로 먼저 알려 줘.
- 아래 정책으로 답할 수 없는 문의는 답장 대신 "대표 확인 필요"라고 표시하고 이유를 적어 줘.

## 배경
- 판매 상품: [예) 수제 반려동물 간식, 1만~3만 원대]
- 판매 채널: [예) 스마트스토어, 인스타그램 DM]
- 말투: [예) 친절하지만 짧게, 이모지는 쓰지 않음, '고객님' 호칭]
- 배송: [예) 평일 오후 2시 이전 주문은 당일 출고]
- 교환·환불: [예) 수령 후 7일 이내 신청, 단순 변심은 왕복 배송비 고객 부담]
- 자주 오는 문의와 답변 기준:
  - [문의 1] → [답변 기준]
  - [문의 2] → [답변 기준]

## 지켜야 할 것
- 위 정책에 없는 보상·할인·환불을 약속하지 마.
- 모르는 내용은 추측하지 말고 "확인 후 다시 안내드리겠습니다"라고 답해.
- 고객 탓으로 들릴 수 있는 표현은 쓰지 마.

## 답장 형식
- 인사 한 줄 → 답변 핵심 → 다음 안내 → 마무리 인사
- [채널]에 맞게 [5]문장 이내
```

</Prompt>

<Callout tone="warn">
교환·환불 기준은 짐작으로 적지 말고, 실제 이용약관과 판매 채널 정책에 적힌 내용을 그대로 옮기세요. 젬은 적힌 정책대로 답하기 때문에 정책이 틀리면 답장도 틀립니다.
</Callout>

### 지침 쓰기가 귀찮다면

지침도 제미나이에게 대신 쓰게 할 수 있어요. 젬 편집 화면에 있는 **제미나이로 지침 다시 쓰기** 버튼으로 내가 적은 초안을 다듬을 수도 있습니다.

<Prompt id="q-gem-writer" kind="quick" name="젬 지침 대신 쓰기">

```text
고객 응대를 도와주는 젬을 만들려고 해.
역할, 할 일, 배경, 형식 네 가지로 지침을 정리해 줘.
필요한 정보는 나한테 하나씩 질문해서 채워 줘.
```

</Prompt>

<Callout tone="tip">
젬 편집 화면의 '지식'에 FAQ 문서, 환불 정책, 상품 목록 파일을 올려 두면 지침에 전부 적지 않아도 그 내용을 참고해서 답합니다.
</Callout>

### 이제는 상황만 던지면 됩니다

<Prompt id="q-gem-use" kind="quick" name="젬에게 답장 맡기기">

```text
환불 문의가 왔어. 답장 써 줘.

[문의 내용]
(고객이 보낸 메시지를 그대로 붙여 넣기)
```

</Prompt>

### 이런 젬도 하나씩 만들어 두세요

- **상세페이지 카피 담당** — 상품 정보를 넣으면 우리 말투로 제목과 소개 문구를 씁니다.
- **리뷰 답글 담당** — 좋은 리뷰와 불만 리뷰에 각각 맞는 답글을 씁니다.
- **견적 정리 담당** — Part 02의 견적서 프롬프트를 지침에 넣어 두면 상담 메모만 붙여 넣어도 됩니다.
- **SNS 게시물 담당** — 신상품이나 이벤트 정보를 넣으면 인스타그램 캡션과 해시태그를 씁니다.

<h2 id="part-07">Part 07. 지메일 연결로 메일 정리부터 답장 초안까지</h2>

### 밤사이 쌓인 메일을 30초 만에 훑기

Part 01에서 Google Workspace를 연결해 두었다면, 제미나이가 내 메일함을 찾아볼 수 있습니다. 입력창에 **@**를 입력하고 **Gmail**을 고른 뒤 요청하면, 메일함에서 찾으라는 뜻이 분명하게 전달됩니다.

"급한 메일"의 기준을 내가 정해 주는 게 핵심이에요. 기준이 없으면 제미나이가 알아서 판단합니다.

<Prompt id="inbox-triage" index="08" name="메일 정리" when="아침에 메일함을 열기 전에, 오늘 답해야 할 메일부터 골라내고 싶을 때 씁니다.">

```text
@Gmail 최근 3일 동안 받은 메일 중에서 내가 답장해야 하는 것만 골라서 정리해 줘.

[급한 메일 기준]
- 결제·환불·배송 사고 같은 고객 불만
- 거래처의 견적·발주·계약 관련 요청
- 본문에 3일 이내 기한이 적혀 있는 메일

[제외할 메일]
- 광고, 뉴스레터, 자동 알림 메일

[정리 형식]
- 급한 순서대로 표로 정리: 보낸 사람 / 제목 / 핵심 요청 한 줄 / 급한 이유 / 답장 기한
- 표 아래에 "오늘 꼭 답할 것"을 3개 이내로 따로 적어 줘.
```

</Prompt>

### 목록 바로 아래에서 답장 초안 받기

정리된 목록 아래에 이어서 답장을 요청하면, 받는 사람과 제목, 본문이 채워진 지메일 작성 화면이 뜹니다. 내용을 확인하고 직접 **보내기**를 눌러야 발송되는 구조예요.

<Prompt id="q-reply-draft" kind="quick" name="답장 초안">

```text
첫 번째 메일에 보낼 답장 초안을 써 줘.
정중하게 쓰고, 원래 메일의 문장을 그대로 따라 쓰지 말고 새 문장으로 써 줘.
내가 확인해야 하는 날짜나 금액은 [ ]로 비워 둬.
```

</Prompt>

<Callout tone="warn">
견적, 계약 조건, 환불 금액이 걸린 메일은 초안을 그대로 보내지 마세요. 숫자와 조건을 원래 메일과 한 번 더 맞춰 본 뒤에 보내기를 누르세요.
</Callout>

<Callout tone="tip">
답장 말투가 중요하다면 Part 06에서 만든 고객 응대 젬을 함께 쓰세요. 메일 내용을 복사해서 젬에 붙여 넣으면 우리 브랜드 말투로 답장이 나옵니다.
</Callout>

<h2 id="part-08">Part 08. 아무도 안 눌러보는 '만들기' 버튼</h2>

### 문서 하나를 웹페이지로 바꿉니다

캔버스에서 문서를 만들면 오른쪽 위에 **만들기** 버튼이 생깁니다. 이 버튼을 누르면 방금 만든 문서를 웹페이지, 인포그래픽, 퀴즈, 오디오 오버뷰 같은 다른 형태로 바꿀 수 있어요.

| 만들기 메뉴 | 사업에 쓰는 법 |
|---|---|
| 웹페이지 | 매장·서비스 소개 페이지, 신메뉴 예고, 행사 안내 페이지 |
| 인포그래픽 | 제안서나 SNS에 넣을 한 장짜리 요약 이미지 |
| 퀴즈 | 직원·아르바이트 교육 내용을 제대로 이해했는지 확인 |
| 오디오 오버뷰 | 긴 자료를 이동하면서 듣기 |

먼저 웹페이지의 재료가 될 소개 문서를 캔버스에 만듭니다.

<Prompt id="intro-page" index="09" name="소개 자료" when="캔버스를 켠 상태에서 보냅니다. 문서가 나오면 만들기 버튼으로 웹페이지나 인포그래픽으로 바꿉니다.">

```text
우리 [매장/서비스] 소개 문서를 만들어 줘. 이 문서는 나중에 웹페이지로 바꿔서 고객에게 링크로 보낼 거야.

[기본 정보]
- 이름: [상호]
- 한 줄 소개: [예) 동네에서 직접 굽는 무설탕 디저트 가게]
- 대표 상품·서비스: [3가지와 각각의 가격]
- 이용 방법: [예) 네이버 예약 후 매장 픽업]
- 위치·운영 시간·연락처: [정보]

[구성]
1. 한 줄 소개와 대표 이미지 자리
2. 이런 분께 추천해요
3. 대표 상품·서비스 3가지
4. 이용 방법 3단계
5. 가격 안내
6. 자주 묻는 질문 3개
7. 위치·연락처와 문의 버튼 자리

[조건]
- 내가 준 정보만 쓰고, 없는 내용은 [입력 필요]로 남겨 줘.
- 후기나 숫자를 지어내지 마.
```

</Prompt>

### 웹페이지로 바꾸는 순서

1. 캔버스에 나온 문서에서 [입력 필요] 부분을 먼저 채웁니다.
2. 오른쪽 위 **만들기**를 누르고 **웹페이지**를 고릅니다.
3. 섹션이 나뉘고 스크롤되는 페이지가 만들어지면, 휴대폰 화면 기준으로 한 번 더 다듬습니다.
4. **공유 및 내보내기 → 공유**에서 링크를 복사해 고객이나 거래처에 보냅니다.

<Prompt id="q-page-mobile" kind="quick" name="모바일 첫 화면 정리">

```text
휴대폰으로 열었을 때 첫 화면에 한 줄 소개와 문의 버튼만 보이게 정리해 줘.
문의 버튼을 누르면 [카카오톡 채널 / 네이버 예약] 링크 [주소]로 이동하게 해 줘.
```

</Prompt>

PDF 파일을 첨부해서 보내는 곳과 링크 하나를 보내는 곳이 있다면, 받는 쪽에서는 링크 쪽이 훨씬 준비된 곳처럼 느껴집니다. 신메뉴 예고나 행사 안내 페이지도 같은 방법으로 만들 수 있어요.

<Callout tone="warn">
신청이나 사전예약용으로 쓸 페이지라도 이름·연락처 입력 칸은 넣지 마세요. 공유한 캔버스 앱의 데이터는 링크를 받은 사람 누구나 보고 수정할 수 있습니다. 신청은 구글 폼이나 네이버 예약 같은 별도 도구로 받고, 페이지에는 그 링크만 연결하세요.
</Callout>

<h2 id="part-09">Part 09. 보너스 · 말로 만드는 짧은 홍보 영상</h2>

### 먼저 요금제를 확인하세요

제미나이의 동영상 만들기는 개인 계정의 경우 구글 AI 요금제가 있어야 쓸 수 있고, 만 18세 이상만 이용할 수 있습니다. 요금제가 있다면 사이드바나 입력창 메뉴의 **동영상 만들기**에서 시작하세요.

알아두면 좋은 점은 이렇습니다.

- 가로·세로 비율은 만들기 전에 고릅니다. 글자로만 요청하면 기본값은 가로형이고, 이미지나 영상을 올리면 올린 파일의 비율을 따릅니다.
- 이미지는 최대 5장, 영상은 1개까지 올릴 수 있습니다.
- 소리를 넣어 달라고 요청할 수 있습니다.
- 만드는 데 몇 분 걸리고, 그동안 같은 대화창은 쓸 수 없습니다. 새 대화에서 다른 일을 하다가 돌아오면 됩니다.

<Prompt id="q-promo-video" kind="quick" name="로고 홍보 영상">

```text
첨부한 로고로 10초짜리 브랜드 홍보 영상을 만들어 줘.
- 흐름: 어두운 화면에서 로고가 천천히 나타나고, 마지막 2초에 "[한 줄 문구]"가 떠오르게
- 분위기: [예) 차분하고 고급스러운]
- 잔잔한 배경음악과 짧은 효과음을 넣어 줘.
- 로고의 모양과 색은 바꾸지 마.
```

</Prompt>

마음에 안 드는 부분은 같은 대화에서 이어서 말하면 됩니다. 영상 편집 프로그램을 켤 필요가 없어요.

<Prompt id="q-promo-video-fix" kind="quick" name="영상 수정">

```text
배경을 검은색으로 바꾸고, 글자가 나타나는 속도를 조금 느리게 해 줘.
나머지는 그대로 유지해 줘.
```

</Prompt>

<Callout tone="warn">
영상 속 로고 모양이나 글자가 원본과 다르게 바뀌어 나올 수 있으니 올리기 전에 꼭 확인하세요. 올리는 이미지와 영상은 내가 사용할 권리가 있는 것만 써야 합니다.
</Callout>
