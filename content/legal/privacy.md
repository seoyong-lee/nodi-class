## 2. 처리하는 개인정보, 목적, 수집 방법

서비스는 회원가입이나 로그인이 없습니다. 아래 네 경우에만 개인정보를 처리합니다.

### 2.1 메일 구독 (자료 열람 포함)

| 항목 | 목적 | 수집 방법 |
| --- | --- | --- |
| 이메일 주소 (필수) | 자료 전달, 새 자료·강의·서비스 소식 안내, 자료 페이지 열람 상태 확인 | 구독 양식에서 동의를 받은 뒤 |
| 지금 만들고 있는 것 (선택, 5개 중 하나) | 어떤 자료를 먼저 만들지 정하는 참고 | 구독 양식 |
| 동의 기록: 동의 시각, 유입 경로, 동의한 문서 버전, IP 주소, 브라우저 정보 | 동의 사실 증명, 부정 이용 방지 | 양식 제출 시 자동 생성 |

메일 구독은 자료 전달과 소식 안내가 한 묶음입니다. 구독하면 자료 페이지가 열리고, 같은 주소로 새 자료·강의·서비스 소식이 갑니다. 이 소식에는 광고성 정보가 포함될 수 있으며, 그런 메일은 제목에 "(광고)"를 표시합니다. 수신을 해지하면 소식이 중단되고 자료 페이지도 닫힙니다.

### 2.2 프로젝트 검토 요청

| 항목 | 목적 | 수집 방법 |
| --- | --- | --- |
| 이름, 이메일 주소 (필수) | 요청 접수, 회신 | 검토 요청 양식 |
| 현재 결과물 링크, 막힌 지점 설명 (필수) | 작업 범위와 견적 검토 | 검토 요청 양식 |
| 접수 시각, IP 주소, 브라우저 정보 | 접수 증빙, 부정 이용 방지 | 양식 제출 시 자동 생성 |

검토 요청 접수 자체는 계약이 아닙니다. 견적과 계약은 이메일로 별도 진행하며, 계약이 체결되면 그때 필요한 정보(세금계산서 발행 정보 등)를 추가로 안내받아 수집합니다.

### 2.3 자료 페이지 열람 상태 쿠키

| 항목 | 목적 | 보관 |
| --- | --- | --- |
| 쿠키 `nodi_access` — 이메일 주소의 해시값과 만료 시각 (이메일 원문은 담지 않음) | 한 번 구독한 브라우저에서 자료 페이지를 다시 열 때 재입력을 생략 | 90일 |

브라우저에서 쿠키를 삭제하거나 차단하면 자료 페이지를 볼 때 이메일을 다시 입력하게 됩니다. 그 외 기능은 영향이 없습니다.

### 2.4 자동으로 생성되는 정보

| 항목 | 목적 |

| 수탁자 | 위탁 업무 | 처리 장소 | 이전 항목·시점 |
