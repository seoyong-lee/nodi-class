# 노디 (nodiworks) 디자인 시스템

유튜브 채널 **노디 AI / 노디의 바이브코딩** (`@nodiworks`) 의 웹사이트를 위한 디자인 시스템입니다.
서비스 운영 주체는 **Cascades** 이고, 푸터와 계약·환불 문구에만 등장합니다. 브랜드 전면에 나서는 이름은 '노디'입니다.

## 이 브랜드가 누구에게 말하는가

- **보는 사람**: 코딩과 디자인을 모르지만 AI로 자기 사업의 랜딩페이지·브랜드·PPT·간단한 서비스를 직접 만들려는 1인 사업자와 예비창업자.
- **어디서 오는가**: 유튜브 영상 → 고정댓글 링크. 사이트에 도착했을 때 "영상에서 보던 그곳"으로 느껴져야 합니다. 다른 브랜드처럼 보이면 실패입니다.
- **화자의 위치**: 전문가가 아니라 **먼저 해본 사람**. 가르치지 않고, 자기가 막혔던 자리를 알려줍니다.
- **사이트가 해야 할 일**: (1) 영상에서 쓴 파일을 무료로 건네고 이메일을 받는다, (2) 유료 상품 두어 개를 오해 없이 설명한다, (3) 영상으로 돌려보낸다. 그 외 목적은 없습니다.

## 자료 출처

이 시스템은 **코드베이스나 Figma 파일 없이** 작성됐습니다. 근거는 두 가지뿐입니다.

1. 사용자가 제공한 브랜드 브리프(타겟·디자인 방향·타이포·레이아웃·컴포넌트 세트·금지 항목).
2. 채널 홈 스크린샷 1장 — 프로젝트의 `uploads/스크린샷 2026-09-12 오전 10.56.14.png`.
   여기서 확인한 것: 채널명 `노디 AI`, 핸들 `@nodiworks`, 배너 락업 **"Build what you imagine / 말하면, 만들어집니다"**(민트 2행),
   채널 소개문 "코딩 몰라도, 이제 AI로 직접 만들 수 있습니다.", 썸네일 문법(검정 배경 + 흰 윗줄 + 민트 아랫줄 + 노란 소형 괄호 문구), 원형 인물 아바타.
   (파일명 인코딩 문제로 `assets/`로 복사하지 못했습니다. 원본은 업로드 폴더에 그대로 있습니다.)
3. 액센트 민트 `#39CD9B` 는 사용자가 직접 지정한 값입니다.

리포지토리·Figma 링크가 생기면 알려주세요. 특히 **실제 로고 파일, 영상 썸네일, 사업자 정보**가 들어오면 이 시스템의 빈칸이 채워집니다.

## CONTENT FUNDAMENTALS — 글은 이렇게 씁니다

**기본 태도**: 담백한 존댓말. 파는 사람이 아니라 먼저 해본 사람의 기록.

| 규칙 | 이렇게 | 이렇게 쓰지 않음 |
| --- | --- | --- |
| 존댓말, 평서 종결 | "영상에서 쓴 파일, 그대로 드립니다." | "지금 바로 받아가세요!" |
| 1인칭 '저', 2인칭은 생략 | "저도 처음엔 세 번 엎었습니다." | "여러분의 성공을 응원합니다" |
| 느낌표 없음 | "30분이면 한 장 나옵니다." | "단 30분 만에!" |
| 기업 어휘 금지 | "같이 한 장 만듭니다." | "혁신적인 솔루션 파트너" |
| 숫자는 사실만 | "39,000원", "섹션 여섯 개" | "만족도 98%", "수강생 1,200명" |
| 약속은 좁게 | "페이지 한 장이 남습니다." | "매출이 오릅니다" |

**세부 규칙**

- **이모지 사용 안 함.** 어디에도 없습니다. 아이콘이 필요하면 Lucide 글리프를 씁니다.
- **조회수·구독자 수 등 채널 지표를 사이트에 노출하지 않습니다.** 영상 카드에도 숫자가 없습니다.
- 버튼 문구는 동사 + 합니다체: "무료 자료 받기", "구매하기", "영상 보러 가기", "자세히 보기".
- 상품 설명은 항상 같은 세 줄 구조 — **누구에게 / 뭐가 남나 / 가격**. 한 줄도 빼지 않고, 네 번째 줄도 만들지 않습니다.
- 라벨은 `01 / 무료 자료` 형식. 숫자는 섹션 순서일 뿐 성과 지표가 아닙니다.
- 개인정보 동의 문구는 항상 12px로 이메일 입력 아래에 붙습니다: "자료 전달과 새 자료 안내 목적으로만 사용하고, 언제든 수신을 해지할 수 있습니다."
- 큰 제목은 의미 단위로 직접 줄을 끊습니다: `말하면,` / `만들어집니다`. 자동 줄바꿈에 맡기지 않고 `word-break: keep-all`을 함께 씁니다.
- 영문은 라벨과 태그라인에만 등장합니다(`BUILD WHAT YOU IMAGINE`, `TEMPLATE`). 문장은 한글로 씁니다.

## VISUAL FOUNDATIONS

### 색

- **다크 베이스, 3단 배경.** `--surface-page #0D1210` → `--surface-card #131917` → `--surface-raised #1A211E`. 입력 필드만 한 단계 더(`--surface-field #212A27`).
- 중립색은 **순수 회색이 아닙니다.** 모든 뉴트럴에 민트 계열(hue ≈ 165) 기운이 3~5% 섞여 있어 액센트와 같은 가족으로 읽힙니다.
- **액센트는 민트 한 색** `#39CD9B`. 쓰이는 곳은 네 군데뿐: Primary 버튼 채움, 텍스트 링크, 현재 상태(현재 내비 항목·열림 뱃지), 입력 포커스 보더.
  아이콘 색·장식 선·배경 면·제목 강조에는 **쓰지 않습니다.**
- 민트 위 글자는 항상 `--mint-ink #06120E`(거의 검정). 민트 위에 흰 글자는 없습니다.
- 텍스트 4단계: `--text-strong #E9F1EE` / `--text-body #A3B0AB` / `--text-muted #7E8C87` / `--text-disabled #3A4642`(상태 표시 전용).
- 태그라인 "Build what you imagine · 말하면, 만들어집니다" 는 민트로 쓰는 **유일한 텍스트**입니다. 채널 배너와 이어지기 때문입니다.

### 타입

- **Pretendard 한 벌**, weight 두 단계(Regular 400 / Bold 700)만 로드합니다. Medium·SemiBold는 없습니다.
- 히어로 h1 60px / line-height 1.15 / letter-spacing -0.02em, 페이지당 한 번. 모바일 375px에서 36px.
- 섹션 제목 30px, 카드 제목 20px — 본문 대비 2배를 넘지 않습니다.
- 본문 16px(카드 안은 15px) / 1.7 / -0.01em, 한 줄 25~40자(`max-width: var(--measure)` = 34em).
- 라벨 12px + `letter-spacing 0.08em` + 대문자 — **영문에만.** 한글 라벨에는 자간을 벌리지 않습니다.

### 여백과 레이아웃

- 최대 폭 **1120px**, 좌우 거터 24px. **좌측 정렬이 기본**이고 중앙 정렬은 히어로와 최종 CTA 두 곳뿐입니다.
- 8px 스케일. 섹션 간 **120px 고정**(페이지마다 조정하지 않음), 섹션 안 요소 간 24~40px, 텍스트 블록 내부는 8~12px(블록 간 간격의 절반 이하).
- 모바일 375px에서 카드 그리드는 1열. 그리드는 `repeat(auto-fit, minmax(…, 1fr))`로 접힙니다.

### 배경·이미지

- 배경은 **단색 면**뿐입니다. 그라데이션 배경·패턴·텍스처·풀블리드 이미지·스톡 사진 **전부 사용하지 않습니다.**
- 이미지가 들어가는 자리는 두 곳: 자료 카드와 영상 카드의 **16:9 썸네일**. 실제 파일이 없으면 `--surface-raised` 빈 슬롯으로 둡니다(가짜 이미지로 채우지 않습니다).
- 실제 썸네일이 들어오면 보정하지 않고 그대로 씁니다. 채널 썸네일은 검정 배경 + 흰/민트 2행 한글 타이포라 사이트와 자연스럽게 붙습니다.

### 엘리베이션·보더·모서리

- **그림자 토큰이 존재하지 않습니다.** 깊이는 배경 명도 한 단계로만 표현합니다(페이지 → 카드 → 강조 블록, 세 단계에서 멈춤).
- 보더는 1px 저대비 두 종류: `--border-subtle #222B28`(기본), `--border-strong #2B3532`(hover·선택).
- 라운딩은 **11px 하나**를 버튼·카드·입력창에 동일 적용. 예외는 뱃지 6px(`--radius-badge`)과 썸네일(카드 라운딩 -3px)뿐입니다.
- 투명·블러는 스티키 헤더 한 곳에서만(`rgba(13,18,16,0.92)` + `blur(8px)`). 유리 효과 패널은 없습니다.
- 보호 그라데이션(이미지 위 텍스트 가독용) 대신 불투명 캡슐을 씁니다 — 영상 카드의 재생 글리프가 그 예입니다.

### 상태와 움직임

- 전환은 200ms `cubic-bezier(0.2,0,0,1)`, 바뀌는 속성은 **색·보더·투명도뿐**입니다.
- Primary hover = 민트가 **밝아짐**(`--mint-400`), press = **어두워짐**(`--mint-600`).
- Secondary hover = 보더만 진해짐, press = 배경이 `--surface-raised`로.
- 카드 hover = 보더만 진해짐. 링크/영상 제목 hover = 민트.
- **transform 없음**: 이동·확대·축소·바운스·그림자 변화 없음. 스크롤 등장 애니메이션도 쓰지 않습니다.
- 포커스는 `outline: 2px solid` 민트 + offset 2px. 입력창은 보더 자체가 민트로 바뀝니다.

### 금지 목록 (브리프 기준)

로고월, 통계 숫자 카드, 팀 소개, 3D 오브젝트, 그라데이션 배경, 스톡 사진, 느낌표, "혁신/솔루션/파트너" 류 기업 어휘, 이모지, 세 번째 폰트 웨이트, 그림자.

## ICONOGRAPHY

- 제공된 소스에 아이콘 세트가 없어 **Lucide**(stroke 2, 라운드 캡)로 대체했습니다. — ⚠️ **대체 항목입니다.** 자체 아이콘이 있으면 교체해 주세요.
- 로딩 방식: `components/core/Icon.jsx`가 `cdn.jsdelivr.net/npm/lucide-static@0.460.0/icons/<name>.svg` 에서 SVG를 한 번 받아 인라인으로 넣고, 글리프의 `stroke="currentColor"`가 주변 글자색을 그대로 따릅니다. 따라서 아이콘은 항상 주변 글자색을 따르고, 민트로 직접 칠하지 않습니다.
- 실제로 쓰는 이름은 여덟 개 남짓: `lock`, `lock-open`, `arrow-right`, `arrow-up-right`, `play`, `check`, `youtube`, `at-sign`, `mail`.
- 아이콘은 **의미가 있을 때만** 씁니다(잠김/열림, 외부 링크, 재생, 소셜). 항목 앞 장식 아이콘은 달지 않습니다.
- **이모지와 유니코드 기호(✓, →, ★)를 아이콘 대용으로 쓰지 않습니다.** 화살표도 Lucide 글리프를 씁니다.
- **로고 파일 없음.** 심볼 마크를 만들지 않았고, 만들어서도 안 됩니다. 로고 자리에는 Pretendard Bold로 브랜드명 '노디'를 씁니다(`guidelines/brand-wordmark.card.html`). 채널 아바타는 인물 사진이라 마크로 쓸 수 없습니다. 실제 로고가 있으면 `assets/logo.svg`로 넣어주세요.

각 컴포넌트 폴더에는 `.jsx`(구현) · `.d.ts`(props 계약) · `.prompt.md`(언제 어떻게 쓰는지) · `*.card.html`(디자인 시스템 탭 카드)이 함께 있습니다.

### 템플릿 (`templates/`)
`landing-page/LandingPage.dc.html` — **노디 랜딩페이지**. 히어로 · 비교 · 무료 자료 + 이메일 게이트 · 상품 · 영상 · 최종 CTA · 푸터가 한 장에 들어 있는 시작점입니다. 소비 프로젝트에서 이 폴더를 복사하고 `ds-base.js`의 `base` 한 줄만 바꾸면 됩니다.

### UI 킷 (`ui_kits/`)
`website/` — 노디 웹사이트 4화면(홈·무료 자료·상품 상세·영상)의 클릭 가능한 재현. 자세한 설명은 `ui_kits/website/README.md`.

### 가이드라인 카드 (`guidelines/`)
Colors 4장 · Type 6장 · Spacing 3장 · Shape 2장 · Motion 1장 · Brand 3장. 디자인 시스템 탭에 그대로 표시됩니다.

### 자산 (`assets/`)
로고·아이콘 원본 없음. 현재 비어 있으며, 실제 로고/썸네일이 들어오면 여기에 둡니다.
